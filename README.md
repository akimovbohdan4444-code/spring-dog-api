# Spring Dog API

Simple REST API written with Spring Boot.

## Technologies

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven

## Features

- Create Dog
- Get Dog by ID
- Get All Dogs
- Update Dog
- Delete Dog
- Validation
- Exception Handling
- DTO
- Mapper

## Endpoints

POST /dog

GET /dogs

GET /dogs/{id}

PUT /dogs/{id}

DELETE /dogs/{id}
